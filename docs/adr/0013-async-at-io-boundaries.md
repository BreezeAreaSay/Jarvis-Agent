# ADR 0013. asyncio только на границах ввода-вывода

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Требование: async только там, где он действительно нужен. При этом нужны таймауты и отмена процессов и
потоковых ответов модели; MCP SDK асинхронный.

## Решение

- Асинхронны: `ModelBackend`, `ProcessRunner`, `ShellParser`, `SkillProvider`, `ToolRuntime.run`,
  стадии и runner.
- Синхронны: домен, политика, L0-роутер, рендер, хранилище (`sqlite3`).
- Отмена — через отмену задачи asyncio; Ctrl+C в CLI вызывает `TaskService.cancel`.
- Тесты — плагин anyio для pytest.

## Альтернативы

- Полностью синхронно с потоками — отмена HTTP и процессов становится запутанной.
- Async везде — шум без пользы.

## Последствия

- Чёткая граница; короткие синхронные вызовы БД внутри асинхронного кода допустимы.
