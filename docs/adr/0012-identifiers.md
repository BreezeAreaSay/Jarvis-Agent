# ADR 0012. Идентификаторы

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

ID нужны для отладки, replay, аудита, UI и тестов. Они должны читаться человеком и быть стабильными.

## Решение

- Задача: `task_<n>`, n — последовательность из БД.
- Дочерние сущности: `task_<n>.<вид>_<k>` (`plan`, `step`, `mc`, `call`, `art`, `appr`, `ev`).
- ID выдаёт порт `IdAllocator`; счётчик увеличивается сразу при выдаче, отдельно от контрольной точки
  задачи. ID никогда не повторяются, пропуски номеров допустимы.
- Нумерация детерминирована: replay задачи даёт сравнимые ID.

## Альтернативы

- UUID и ULID — нечитаемы.
- Автоинкремент в каждой таблице — replay несравним.

## Последствия

- Сбой такта оставляет пропуск в нумерации, но не повтор ID.
- Перенумерация невозможна, и она не нужна.
