# ADR 0001. Python 3.12+, один пакет, uv

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Stage 0 — один процесс (CLI с ядром). Экосистема для локальных моделей, MCP и автоматизации Windows
сильнее всего в Python. В архитектуре предлагался uv workspace из нескольких пакетов, но второго процесса
пока нет.

## Решение

- Python ≥ 3.12, типизация везде; pyright в строгом режиме для `domain`, `ports`, `core`.
- Один пакет `jarvis` в src-layout; окружение и lock-файл — uv.
- ruff (линтер и форматирование), pytest с плагином anyio.
- Workspace из нескольких пакетов — когда появится отдельный голосовой процесс (Stage 3).

## Альтернативы

- Workspace сразу — преждевременные границы и лишняя оснастка.
- poetry — медленнее, слабее поддержка workspace.
- Ядро на Rust или Go — медленнее разработка, беднее экосистема для моделей и MCP.

## Последствия

- Простая установка: `uv sync`.
- Границы модулей держатся правилами импорта (ADR 0002), а не упаковкой.
- Выделение пакетов позже — механическая работа благодаря портам.
