# ADR 0007. Skills ≠ Recipes; SkillProvider и NullSkillProvider

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Понятие «skill» смешивало знание для модели и детерминированную процедуру. AI-Dev-System — отдельный
продукт и источник знаний.

## Решение

- `Skill` — знание или инструкция для модели; всегда недоверенный текст; источник — `SkillProvider`
  (`search`, `get`, `get_project_context`).
- `Recipe` — детерминированный workflow, принадлежит Jarvis; в Stage 0 не реализуется, и в коде нет ни
  типов, ни интерфейсов для него.
- `NullSkillProvider` есть всегда; Jarvis полностью работает без MCP.
- Адаптер AI-Dev-System — необязательный M10.

## Альтернативы

- Один тип «skill» с необязательными шагами — смешение понятий.
- Интерфейсы рецептов сейчас — код без потребителя.

## Последствия

- Stage 1 добавит пакет `recipes`, не затрагивая навыки.
