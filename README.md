# Jarvis

Локальный **Agent Runtime** для ПК: демон, который понимает текстовые и голосовые команды на русском,
работает с ОС и приложениями, планирует и проверяет сложные задачи, использует инструменты и навыки,
помнит пользователя и его проекты. Голосовой ассистент, CLI и desktop UI — клиенты этого рантайма.

> **Статус:** Stage 0 реализован (ядро задач, хранилище, Tool Runtime с политикой, агент на локальной
> модели, eval и бенчмарк); предложена Architecture V2 — гибридная local-first архитектура по итогам
> бенчмарка на целевом ПК.

## Главное

- **Local-first, cloud-augmented:** простое — детерминированно и без модели, приватное — на локальной
  модели (Qwen3-8B через llama.cpp), сложное — у облачных провайдеров и внешних агентов за границей
  приватности; облако не обязательно для работы.
- **Оркестрация вместо одной LLM:** Router ядра выбирает способ исполнения — прямая команда, рецепт,
  короткий агентный цикл или внешний агент-специалист; модель не решает, как исполнять задачу.
- **Безопасность с первого дня:** единая точка исполнения действий с политикой, подтверждениями,
  аудитом и журналом эффектов.
- **Навыки:** руководства из [AI-Dev-System](https://github.com/BreezeAreaSay/ai-dev-system) (MCP) +
  исполняемые рецепты, которые Jarvis учит на повторяющихся сценариях.
- **Windows-first:** сначала API, URL, deep link, протоколы браузера и команды ОС; UI Automation и vision —
  запасные пути.
- **Поставка:** `.exe`-установщик, обновления из GitHub Releases только с разрешения пользователя.
