# Jarvis

Голосовой ассистент для Windows: скажите «**Джарвис**, включи музыку» — и готово. Распознавание речи работает
прямо на компьютере, без интернета. Живая сфера-аватар, больше тысячи команд, паки команд для десятков программ,
сценарии, Jarvis AI с поиском в интернете и памятью (по подписке ChatGPT или Claude, или по ключу любого из
двух десятков провайдеров), агент, который сам работает на компьютере, столы из виджетов, 12 плагинов и пульт
в телефоне.

> Версия 2.0 — полный перезапуск проекта. Прежняя реализация осталась в истории git (ветки `main` и `jarvis-v1`).

| **Редактор команд** | Свои команды из действий (запуск программ, сочетания клавиш, клики, громкость, паузы, речь…), запись действий, «Создать с помощью AI» по описанию словами, свои фразы запуска |

## Установка

1. Скачайте `Jarvis-Setup-<версия>.exe` и запустите (права администратора не нужны).
2. При первом запуске мастер поможет выбрать микрофон, скачает голосовые модели (~260 МБ, один раз) и
   подключит ИИ (можно пропустить — команды работают без него). Если на компьютере была старая версия Jarvis
   (1.x), сначала удалите её и переменную среды `JARVIS_DATA_DIR`, если задавали.
3. Скажите «Джарвис, сверни все окна».

Установщик не подписан цифровой подписью — Windows SmartScreen может предупредить: «Подробнее → Выполнить
в любом случае».

## Обновления

Jarvis сам проверяет новые версии на GitHub — при запуске и каждые 6 часов, — качает их в фоне и предлагает
перезапуститься (уведомление, пункт в трее и «Настройки → Система → Обновления», там же «Проверить сейчас»).
Новая версия ставится тихо поверх старой; настройки, модели и история остаются.

Выпуск версии:

1. Поднять версию в `desktop/package.json`, `core/pyproject.toml` и `core/jarvis/__init__.py`.
2. Собрать установщик: `pwsh -File scripts\build-win.ps1` — в `desktop\release` появятся
   `Jarvis-Setup-<версия>.exe`, `Jarvis-Setup-<версия>.exe.blockmap` и `latest.yml`.
3. Опубликовать: `pwsh -File scripts\publish-release.ps1 -Notes "что нового"` (нужен
   [GitHub CLI](https://cli.github.com): `winget install GitHub.cli`, `gh auth login`) — или вручную: новый релиз
   на GitHub с тегом `v<версия>` и этими тремя файлами. Без `latest.yml` приложение версию не увидит.

## Запуск из исходников (Windows)

Нужны [uv](https://docs.astral.sh/uv/) и Node.js 22+.

```powershell
pwsh -File scripts\dev.ps1        # ядро + интерфейс с горячей перезагрузкой
pwsh -File scripts\build-win.ps1  # установщик: desktop\release\Jarvis-Setup-<версия>.exe
```

На Linux ядро для Windows-установщика собирается без Wine: `scripts/build-core-win.sh`, затем
`cd desktop && npm run dist` (для значка exe нужен Wine).

## Устройство

```
desktop/   Electron + React: главное окно, оверлей поверх окон, аватар, трей, хоткеи; запускает ядро
core/      Python 3.12 + FastAPI: голос, команды, ИИ, агент, MCP, плагины, виджеты, пульт (HTTP + WebSocket)
docs/      CONTRACTS.md — API и события ядра; UI.md — правила интерфейса
scripts/   сборка и запуск
```

Данные — `%LOCALAPPDATA%\Jarvis` (или папка из `JARVIS_DATA_DIR`): настройки, база, модели, журналы; ключи API
зашифрованы DPAPI. Ядро — только на 127.0.0.1, каждый запрос с токеном.

## Разработка

```bash
cd core && uv sync && uv run pytest -q          # тесты ядра (на Linux — с платформой-заглушкой)
cd desktop && npm install && npm run typecheck  # проверка типов интерфейса
```

Интерфейс без Electron: `uv run python -m jarvis --platform fake --token devtoken --port 8799` и
`npm run web`, затем `http://127.0.0.1:5173/?core=http://127.0.0.1:8799&token=devtoken`.
