# ADR 0019. Без демона в Stage 0

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Архитектура предполагает демон `jarvisd` и клиентов. В scope Stage 0 фоновый демон не входит, если он не нужен.

## Решение

- CLI выполняет ядро в своём процессе через `TaskService` — тот же API, который позже выставит сервер.
- Состояние в SQLite, поэтому второй процесс CLI может показать задачи, подтвердить, продолжить ожидающую
  задачу или отменить задачу без живой аренды. Работающую задачу отменяет её собственный процесс (Ctrl+C).
- Демон — Stage 2.

## Альтернативы

- Демон с IPC уже в Stage 0 — протокол, жизненный цикл и автозапуск без потребителя.
- Флаг отмены в строке задачи, который опрашивает работающий процесс, — конфликтует с оптимистической
  блокировкой и усложняет runner ради редкого сценария.

## Последствия

- Фоновых задач нет.
- Отменить работающую задачу из другого терминала нельзя (`TaskBusy`); это снимается демоном в Stage 2.
