# ADR 0019. Без демона в Stage 0

- **Статус:** Предложено
- **Дата:** 2026-10-01

## Контекст

Архитектура предполагает демон `jarvisd` и клиентов. В scope Stage 0 фоновый демон не входит, если он не нужен.

## Решение

- CLI выполняет ядро в своём процессе через `TaskService` — тот же API, который позже выставит сервер.
- Состояние в SQLite, поэтому второй процесс CLI может показать задачи, подтвердить, отменить или продолжить.
- Демон — Stage 2.

## Последствия

- Фоновых задач нет.
- Отмена из другого терминала — через флаг в БД, который проверяют runner и Tool Runtime.
