# Примеры облачных провайдеров (V2.2)

Фрагменты `config.toml` для OpenAI-совместимых провайдеров. Это **шаблоны**, а не проверенные профили:

- ключей здесь нет и быть не должно — только ссылка `api_key = "env:ИМЯ"`; сам ключ задаётся переменной
  окружения (в PowerShell: `$env:JARVIS_SMART_API_KEY = "…"`, постоянно — «Переменные среды» Windows);
- адреса, имена моделей, лимиты и поддержка JSON-режима меняются — сверьте их с документацией провайдера
  перед использованием; `jarvis model check --remote` проверит адрес, ключ и пробный запрос;
- доступность из России, способы регистрации и оплаты **не проверялись**: из среды разработки этого не
  проверить. Jarvis не предполагает обхода региональных ограничений — в цепочки ставьте тех провайдеров,
  которыми можете пользоваться законно;
- данные у таких провайдеров обрабатываются по законам их юрисдикции. Поэтому по умолчанию облако
  выключено, а содержимое файлов, код и личные данные не уходят без вашего решения (ADR 0028).

Как подключить: скопируйте нужный фрагмент в `JARVIS_HOME/config/config.toml` (рядом с локальной моделью
`[models.endpoints.main]` и `[models.roles]`), включите облако и добавьте провайдера в цепочку уровня:

```toml
[cloud]
enabled = true

[models.routing]
smart = ["smart_primary", "smart_secondary"]   # локальная модель добавляется последней сама
coding = ["coding_primary", "smart_primary"]
```

| Файл | Провайдер (по документации на момент написания) | Заметки |
| --- | --- | --- |
| `kimi.toml` | Moonshot AI (Kimi) | JSON Schema не применяет — `json_object = true` |
| `glm.toml` | Zhipu / Z.ai (GLM) | рассуждения выключаются через `extra_body` |
| `deepseek.toml` | DeepSeek | у «рассуждающей» модели рассуждения расходуют лимит вывода |
| `qwen-dashscope.toml` | Alibaba Cloud Model Studio (Qwen, режим совместимости) | международный и китайский адреса различаются |

Несовместимости, известные заранее: многие провайдеры не применяют `response_format: json_schema` —
Jarvis тогда описывает схему в промпте, проверяет и чинит ответ (`structured_output = false`,
`json_object = true`). Свои признаки исчерпанной квоты в ответе 429 добавляются в `quota_markers`.
