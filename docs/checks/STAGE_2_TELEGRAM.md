# Проверка этапа «Telegram» на Windows — промт для Codex

Этап «Telegram» плана ([IMPROVEMENT_PLAN.md](../IMPROVEMENT_PLAN.md)): снимок окна Telegram одним запросом
UI Automation, действия агента `telegram_send` и `telegram_read`, голосовые команды «напиши … в телеграме …» и «что
написал … в телеграме» без ИИ. На Linux это проверено тестами и имитатором; ниже — то, что можно проверить только
в настоящем Telegram Desktop. Скрипты — в `docs/checks/stage2/`.

**Писать — только в «Избранное» (Saved Messages).** Скрипт `tg_command.py` сам отклоняет отправку в любой другой
чат.

Скопируйте промт целиком в Codex на ПК владельца.

---

Ты проверяешь ветку `dev` проекта Jarvis (голосовой ассистент для Windows,
https://github.com/BreezeAreaSay/Jarvis-Agent) на этом ПК: Windows 11, масштаб 100 %, один монитор, имя
пользователя — кириллицей, установлен Telegram Desktop.

## Правила

- Работай только в `C:\jarvis-check`: клон, данные, журналы, отчёт. Вне неё ничего не создавай и не меняй.
- Код проекта не меняй, ничего не коммить и не отправляй. Свои вспомогательные файлы клади в
  `C:\jarvis-check\work`.
- Ничего не делай от администратора. Ни в какие аккаунты не входи и пароли не вводи.
- **Сообщения — только в «Избранное» (Saved Messages)**, никогда в чаты людей, группы и каналы. Фразы команд
  бери ровно из этого промта.
- **Перед каждым шагом с окнами, мышью и клавиатурой спрашивай владельца** и жди ответа «да». Пока идёт такой
  шаг, проси владельца не трогать мышь и клавиатуру.
- Личное (имена чатов, сообщения) в отчёт не переписывай: только числа, время, да/нет и тексты ошибок.
  `--show` — только с согласия владельца, и в отчёт из его вывода — только типы элементов, без имён.
- Python — только от uv (`UV_PYTHON_PREFERENCE=only-managed`), не из Microsoft Store.
- Итог — отчёт `C:\jarvis-check\report-stage2.md` с фактами: команды, JSON скриптов (без личного), что прошло, что
  нет и с каким текстом ошибки. Не исправляй найденное — опиши.

## 0. Подготовка

```powershell
New-Item -ItemType Directory -Force C:\jarvis-check, C:\jarvis-check\work, C:\jarvis-check\data | Out-Null
cd C:\jarvis-check
if (Test-Path Jarvis-Agent) { Remove-Item -Recurse -Force Jarvis-Agent }
git clone --branch dev https://github.com/BreezeAreaSay/Jarvis-Agent.git
cd C:\jarvis-check\Jarvis-Agent\core
$env:UV_PYTHON_PREFERENCE = "only-managed"
$env:PYTHONUTF8 = "1"
$env:JARVIS_DATA_DIR = "C:\jarvis-check\data"
uv sync --locked --python 3.12
```

Если `git clone` просит войти в GitHub — остановись и спроси владельца (сам не входи). Запиши версии:
`uv run python --version`, `git log -1 --oneline`, `[Environment]::OSVersion.Version`, версию Telegram Desktop
(«Настройки» → внизу; или свойства `Telegram.exe`) и язык его интерфейса (русский или английский).

## 1. Тесты (без окон и мыши)

```powershell
uv run --with pytest-timeout pytest -q --timeout 120 tests/ai/test_telegram_desktop.py tests/evals/test_telegram_command.py tests/ai/test_web_page.py
uv run --with pytest-timeout pytest -q --timeout 300 --deselect tests/platform/test_win_platform.py::test_live_clipboard_roundtrip
uv run python -m evals.routing
uv run python -m evals
```

Ожидается: тесты проходят; `evals.routing` — `"ok": true`, `false_launches` пустой; `evals` — 23 из 23. Падения —
в отчёт с текстом.

## 2. Снимок окна Telegram (спроси владельца: окно Telegram выйдет вперёд)

Попроси владельца открыть Telegram Desktop (не свёрнутым) **без открытого чата** (Esc закрывает чат).

```powershell
uv run python ..\docs\checks\stage2\tg_snapshot.py --focus
```

Потом попроси открыть «Избранное» (Ctrl+0) и повтори. Ожидается:
- `снимок_секунд` — каждое меньше 0,5 (раньше было 3–4,6);
- `поле_поиска` — не `null` (лучше — «UI Automation»);
- с открытым «Избранным»: `поле_сообщения` — не `null`, `строк_в_шапке` — больше 0.

Запиши оба JSON целиком (в них нет личного). Если `поле_поиска` или `поле_сообщения` — `null`: с согласия
владельца запусти с `--show` и опиши, **какого типа** элементы есть у поиска, у шапки и у поля сообщения (типы и
места, без имён чатов и текстов).

## 3. Голосовые команды без ИИ (спроси владельца: окно Telegram, мышь и клавиатура)

Скрипт выполняет ту же команду, что фраза голосом: Jarvis сам выводит Telegram вперёд, ищет чат, проверяет
шапку, печатает текст и спрашивает разрешения на отправку. Разрешает скрипт только отправку в «Избранное».
Перед каждым запуском попроси владельца не трогать мышь и клавиатуру. Если интерфейс Telegram английский — в
фразах вместо «избранному» / «избранное» говори «saved messages».

```powershell
# 3.1 отправить в «Избранное»
uv run python ..\docs\checks\stage2\tg_command.py --phrase "напиши избранному в телеграме проверка связи раз два три" --allow
# 3.2 отказ: ничего не уходит, набранное стирается
uv run python ..\docs\checks\stage2\tg_command.py --phrase "напиши избранному в телеграме проверка отказа" --deny
# 3.3 прочитать «Избранное» (текст сообщений не печатается)
uv run python ..\docs\checks\stage2\tg_command.py --phrase "прочитай избранное в телеграме"
```

Ожидается:
- 3.1: `итог` — `ok`, в `вопросы` — один «Отправить в Telegram «Избранное»?» с `разрешено: true`, ответ «Отправил в
  Telegram «Избранное»: «Проверка связи раз два три».». Спроси владельца: сообщение появилось в «Избранном» один раз?
- 3.2: `итог` — `ошибка`, ответ «Не стал: вы не разрешили.». Спроси владельца: в «Избранном» нового сообщения нет,
  поле ввода пустое?
- 3.3: `итог` — `ok`, ответ «(прочитано N знаков…)».

Затем три трудных начала (каждое — с разрешения владельца, повтори 3.1 с другим текстом):
- 3.4: Telegram **свёрнут** — команда сама разворачивает его.
- 3.5: впереди **другая программа** (Блокнот, Проводник) — команда сама выводит Telegram.
- 3.6: в Telegram открыт **любой другой чат** — команда открывает «Избранное», а не пишет в открытый чат (скрипт
  и так не разрешит отправку в другой чат: в `вопросы` должен быть вопрос именно про «Избранное»).

Для каждого запуска запиши JSON (поле `ответ` у 3.3 — как есть, текста в нём нет), `секунд` и что сказал владелец.
Если команда закончилась ошибкой — текст ошибки целиком.

## 4. Уборка

Закрой то, что открывал сам. Сообщения «проверка связи…» в «Избранном» владелец удалит сам, если захочет. Папку
`C:\jarvis-check` не удаляй — в ней отчёт.

## Отчёт `C:\jarvis-check\report-stage2.md`

1. Версии (Windows, Python, коммит, Telegram Desktop и язык его интерфейса).
2. Тесты: числа «passed/failed/skipped», тексты падений; итог `evals.routing` и `evals`.
3. Снимок окна: оба JSON, время каждого снимка, найдены ли поле поиска, шапка и поле сообщения.
4. Команды: таблица «проверка × итог × секунд × вопросы × что видел владелец».
5. Что не удалось проверить и почему.
