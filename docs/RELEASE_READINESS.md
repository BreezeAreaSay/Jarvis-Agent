# Готовность к публичному релизу

Срез на ветке с фоновыми задачами (заметки — `docs/releases/v3.1.0.md`, версия ещё не поднята). Что сделано,
что проверить на Windows руками и чего не хватает до выпуска «для всех».

## Сделано

- **Фоновые задачи** (docs/BACKGROUND_TASKS.md, этап 1): очередь, несколько задач сразу, вопросы человеку с паузой
  и продолжением, продолжение после перезапуска, отмена и повтор; запуск со страницы, из чата и голосом («в фоне:
  …»); все провайдеры — Codex, Claude Code, Gemini CLI, Qwen Code и ключ API.
- **Браузер агента**: свой Chrome или Edge без окна, вкладка на задачу, живая картинка в окне Jarvis, «Взять
  управление», «Войти на сайты»; деньги, отправка, публикация, удаление — с разрешения; пароли и карты агент
  не вводит; скачивание и загрузка файлов выключены.
- **Obsidian**: хранилище находится само, своя папка `Jarvis/`, запись только в неё, заметки задач с итогом,
  планом и источниками.
- **Настройки** «Фоновые задачи»: хранилище, самостоятельность, лимиты, уведомления о вопросе и итоге.
- **Цикл агента на экране**: стабильные id элементов, пачка действий до первой ошибки, детектор хождения
  по кругу, мягкий лимит шагов, температура 0.2.
- **Оформление**: лицензия PolyForm Noncommercial 1.0.0 (`LICENSE.md`, `package.json`, `pyproject.toml`, «О
  программе»), README к публикации со скриншотами (`docs/screenshots`), CONTRIBUTING.md, SECURITY.md, шаблоны
  задач GitHub.
- Тесты ядра: 1954 прошли, 9 пропущено; проверочные задачи агента (`core/evals`, имитатор): 18 из 18, как
  до изменений. Браузер агента проверен вживую с настоящим Chromium на Linux (запуск, подпись, картинка,
  щелчки из панели).

## Проверить на Windows перед выпуском

Всё ниже на Linux не проверить — нужен живой прогон на Windows 10 и 11.

- [ ] Браузер агента: находится Chrome, без Chrome — Edge; не мелькает окно и консоль; второй Chrome рядом
      с вашим открытым Chrome не мешает ему; закрывается сам через 10 минут простоя и при выходе из Jarvis
      (не остаётся процессов `chrome.exe`).
- [ ] «Войти на сайты»: вход в Google, Яндекс, VK, Telegram Web, маркетплейсы из панели. **Google часто не
      пускает браузер без окна** («Этот браузер может быть небезопасен») — если так, это первое, что нужно
      из этапа 2 («Открыть окном»).
- [ ] Ввод в панели: русская раскладка, Ctrl+C / Ctrl+V, прокрутка, правая кнопка, двойной щелчок; картинка
      не отстаёт на 4K и при масштабе Windows 125–150 %.
- [ ] Obsidian: хранилище находится по `%APPDATA%\obsidian\obsidian.json`; заметки с русскими именами
      открываются в Obsidian; ссылки `[[…]]` ведут куда надо; OneDrive-папка с хранилищем.
- [ ] Задача по подписке: Codex (ChatGPT) и Claude Code — поиск в интернете, вопрос и ответ, итог в заметке;
      то же по ключу API (OpenAI, Anthropic, OpenRouter) и на Ollama.
- [ ] Уведомления: всплывающее, голосом, в Telegram — о вопросе и об итоге; «тихо», когда ничего не выбрано.
- [ ] «В фоне: …» голосом и в чате; две задачи сразу; перезапуск Jarvis посреди задачи — продолжается.
- [ ] Экранный агент на прежних сценариях (Telegram, Spotify, Steam, проводник) — не хуже 3.0.

## Нужно до публичного релиза

1. **Подпись установщика.** Без неё SmartScreen пугает каждого нового пользователя, а антивирусы чаще
   ругаются — для «выпуска обществу» это главный барьер. Бесплатная подпись SignPath Foundation требует
   лицензии, одобренной OSI, — с PolyForm Noncommercial она не подходит; нужен свой сертификат OV или EV
   (CONTRIBUTING.md, «Подпись установщика»).
2. **CI на GitHub** не запускается на аккаунте — без него сборка по тегу и проверки не работают; чинит владелец.
3. **Живые прогоны с настоящей моделью**: `core/evals` пока гоняется на имитаторе; нужны прогоны экранного
   агента с Codex, Claude Code и ключом API и несколько проверочных фоновых задач (поиск → сравнение → заметка),
   чтобы ловить откаты.
4. **Выпуск 3.1.0**: поднять версию (CONTRIBUTING.md, «Выпуск версии»), пройти список «Проверить на Windows».

## Следующие этапы фоновых задач

- **Этап 2 — удобство**: «Открыть окном» для сайтов, которые не пускают браузер без окна (вход Google, сложные
  капчи); ответы на вопросы задачи прямо из Telegram; утверждение плана большой задачи перед стартом;
  скачивание файлов с разрешения (в отдельную папку, без запуска).
- **Этап 3 — расписания и замеры**: задача по расписанию через «Сценарии» («каждый вечер записывай …»),
  таблицы замеров с дописыванием строк, `Входящие.md` — задачи из заметки, источники для NotebookLM (у
  NotebookLM нет открытого API для обычных аккаунтов — только выгрузка заметок, которые человек добавит сам).

## Где конкуренты пока сильнее

- **Окна без UI Automation** (игры, Electron-программы без доступности, удалённый рабочий стол): у Jarvis нет
  распознавания текста на экране (OCR) и привязки к найденному на картинке — агент полагается на дерево
  элементов и снимок. У UFO2 и Agent S — гибрид «дерево + зрение».
- **Ключ Anthropic** работает через совместимый с OpenAI адрес: нет кэша промпта и родных инструментов Messages
  API — длинные задачи по ключу дороже, чем могли бы быть. Родной клиент Anthropic с кэшем окупится быстрее
  всего у фоновых задач.
- **Действия без интерфейса**: у агента нет своей оболочки (PowerShell) для дел, которые проще сделать
  командой, чем мышью (файлы, настройки, процессы); сейчас — только команды Jarvis и окна.
