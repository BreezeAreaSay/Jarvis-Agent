## Jarvis 3.2.0

### Telegram — голосом и одним действием
- **«Напиши Ане в телеграме: буду в семь» — без ИИ.** Jarvis сам открывает Telegram Desktop, находит чат по
  имени (понимает «Ане», «Маме», «Ане Смирновой» — в любом падеже), проверяет по шапке, что открыт нужный чат,
  набирает текст и показывает его перед отправкой. Отправляет только после вашего «Разрешить». Подходят несколько
  чатов — спросит, какой («второй», «Смирновой»). Работает и без настроенного ИИ — ни ключа, ни подписки не нужно.
- **«Что написал папа в телеграме?»** — Jarvis откроет чат и прочитает последние сообщения вслух, тоже без ИИ.
- **Агент пишет в Telegram за один шаг вместо 6–10.** «Найди чат, проверь, набери, отправь» — одно действие
  агента с теми же проверками: быстрее и без промахов по соседнему чату.
- **Окно Telegram читается в разы быстрее** — одним запросом вместо обхода дерева (было 3–4,6 с на снимок).
- Отказались отправлять — набранный текст стирается из поля, а не остаётся черновиком. Черновик, который вы
  начали сами, Jarvis не трогает.

### Агент на экране — видит больше и попадает точнее
- **Читает текст там, где окно «немое».** Telegram, программы на Qt, игры и окна без доступности почти не видны
  UI Automation: раньше агент знал о них только по картинке, а модель без зрения — почти ничего. Теперь Jarvis сам
  распознаёт текст в таком окне средствами Windows (без сети, за сотые доли секунды) — чаты, имена, надписи на
  кнопках — и агент нажимает их по строке, даже если модель не понимает картинки.
- **Попадает, куда целится, на больших экранах.** Координаты элементов в описании окна теперь совпадают с
  картинкой, которую видит модель: на мониторах шире 1568 точек агент больше не промахивается мимо кнопок.

### Надёжность
- **Браузер фоновых задач не остаётся «призраком».** Если ядро Jarvis упало или его закрыли принудительно, его
  невидимый Chrome теперь закрывается вместе с ним, а не висит в диспетчере задач.
