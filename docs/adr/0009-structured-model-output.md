# ADR 0009. Структурированный вывод модели; схема проверяется до политики

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Модель не должна возвращать исполняемый произвольный текст.

## Решение

- Router, Planner, Executor и Verifier отвечают JSON по pydantic-схеме; при поддержке бэкенда —
  ограниченное декодирование.
- Конвейер: разбор → схема → семантическая проверка → ремонт (не больше N попыток) → `InvalidModelOutput`.
- В политику попадают только прошедшие проверку действия.
- Действие исполнителя — объединение `tool | step_done | replan | finish` с полем `decision`
  (≤ 280 символов); одно действие за шаг.

## Альтернативы

- Нативные вызовы инструментов — разные форматы у разных моделей.
- Свободный текст и регулярные выражения — хрупко.

## Последствия

- Схемы — часть контракта и версионируются вместе с промптами.
- Малые модели получают помощь грамматики.
