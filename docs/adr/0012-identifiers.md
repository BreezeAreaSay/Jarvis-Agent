# ADR 0012. Идентификаторы

- **Статус:** Предложено
- **Дата:** 2026-10-01

## Контекст

ID нужны для отладки, replay, аудита, UI и тестов. Они должны читаться человеком и быть стабильными.

## Решение

- Задача: `task_<n>`, n — последовательность из БД.
- Дочерние сущности: `task_<n>.<вид>_<k>` (`plan`, `step`, `mc`, `call`, `art`, `appr`, `ev`) со счётчиками,
  которые хранятся в задаче.
- Нумерация детерминирована: replay задачи даёт сравнимые ID.

## Альтернативы

- UUID и ULID — нечитаемы.
- Автоинкремент в каждой таблице — replay несравним.

## Последствия

- ID дочерних сущностей зависят от строки задачи; перенумерация невозможна, и она не нужна.
