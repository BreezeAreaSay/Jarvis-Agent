# ADR 0016. Dry run и replay

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Нужны безопасная разработка и отладка, тестирование навыков и будущего UI, воспроизведение задач.

## Решение

- Режимы исполнения: `normal`, `dry_run`, `replay_simulated`, `replay_live`.
- Инструменты с эффектами реализуют `simulate`; в dry run инструменты без эффектов исполняются по-настоящему.
- Replay использует записанные ответы модели и результаты инструментов, сообщает о расхождениях и
  пересчитывает политику.
- Live replay никогда не исполняет HIGH и CRITICAL; эффекты — только с явным флагом и не выше MEDIUM.

## Последствия

- Запись вызовов модели обязательна.
- Каждый инструмент с эффектами реализует `simulate`.
