# ADR 0020. Eval с первого milestone и бенчмарк до выбора модели

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Главный вопрос Stage 0 — способна ли локальная модель на реальном железе стабильно выполнять агентные
задачи. Ответ нужен в цифрах.

## Решение

- Движок eval — с M1; scripted-режим в CI, live — на ПК пользователя. У каждого сценария указан
  milestone, с которого он идёт в CI; до появления модели сценарии используют scripted-стадии.
- Свойства golden-трасс вместо сравнения текста рассуждений.
- Метрики на каждый сценарий.
- Аппаратный бенчмарк трёх классов моделей; основная модель выбирается по правилу, результат фиксируется ADR.

## Альтернативы

- Eval после готовности агента — механика ядра остаётся без сквозной проверки до M8.
- Выбор модели по публичным рейтингам — не учитывает железо пользователя, русский и structured output.

## Последствия

- Каждая возможность приходит вместе со сценариями.
- Выбор модели основан на данных, а не на популярности.
