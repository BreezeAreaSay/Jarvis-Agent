# Jarvis

Голосовой ассистент для Windows: скажите «**Джарвис**, включи музыку» — и готово. Распознавание речи работает
прямо на компьютере, без интернета. Живая сфера-аватар, свои команды, паки команд для десятков программ,
Jarvis AI с поиском в интернете и памятью, агент, который сам работает на компьютере, столы из виджетов,
плагины и пульт в телефоне.

> Версия 2.0 — полный перезапуск проекта. Прежняя реализация осталась в истории git (ветки `main` и `jarvis-v1`).

## Возможности

| | |
|---|---|
| **Голос** | Слово-активатор «Джарвис» (можно своё), распознавание на ПК (GigaAM v3 + Silero VAD, sherpa-onnx), продолжение диалога без повторного «Джарвис», «держи и говори», тихий режим |
| **Голос ответа** | Локальный голос Джарвиса (piper, с «электроникой»), голос Windows, Microsoft Edge, OpenAI, Fish Audio (в том числе свои голоса) |
| **Команды** | Сотни встроенных команд: громкость, медиа, окна, программы, сайты, поиск, клавиатура, браузер, система, папки, таймеры, погода и время; цепочки «сверни все окна и включи музыку» |
| **Редактор команд** | Свои команды из действий (запуск программ, сочетания клавиш, клики, громкость, паузы, речь…), запись действий, «Создать с помощью AI» по описанию словами, свои фразы запуска |
| **Паки команд** | Готовые паки для Spotify, Chrome, Photoshop, OBS, Discord, Telegram, VS Code, Minecraft, CS2, Dota 2 и других — в один клик |
| **Jarvis AI** | Чат с инструментами: свежие новости и погода из интернета с источниками, выполнение команд прямо в разговоре, память о вас, заметки, задачи, календарь, напоминания. Провайдеры: OpenAI, Anthropic, DeepSeek, OpenRouter, Groq, локальные Ollama и LM Studio, любой OpenAI-совместимый |
| **Агент** | «Работает сам»: открывает программы, нажимает кнопки, вводит текст (UI Automation) и спрашивает разрешения перед отправкой и удалением |
| **MCP** | Подключение MCP-серверов (stdio и HTTP) и каталог из официального реестра MCP |
| **Столы и виджеты** | Главная из виджетов: погода, задачи, курсы ЦБ, крипта, акции, музыка, календарь, система, программы, новости и др.; 12 заготовок столов; «открой стол Игры» голосом |
| **Плагины** | Умный дом (Home Assistant, Яндекс), умная диктовка, живые субтитры с переводом, конспект созвонов, чтение вслух, блокировка, когда отходишь, второй компьютер, озвучка уведомлений, питомец |
| **Аватар и оверлей** | Живая сфера на рабочем столе, строка голоса и уведомления поверх окон, пиксельный питомец |
| **Пульт в телефоне** | Telegram-бот «PC Control» (из любой точки) и страница в браузере телефона по Wi-Fi с QR-кодом |
| **Настройки** | Цвет темы, прозрачность, размытие, анимации, горячие клавиши, автозапуск, трей и десятки других параметров |

## Установка

1. Скачайте `Jarvis-Setup-<версия>.exe` и запустите (права администратора не нужны).
2. При первом запуске мастер поможет выбрать микрофон, скачает голосовые модели (~260 МБ, один раз) и
   подключит ИИ (можно пропустить — команды работают без него).
3. Скажите «Джарвис, сверни все окна».

Установщик не подписан цифровой подписью — Windows SmartScreen может предупредить: «Подробнее → Выполнить
в любом случае».

## Запуск из исходников (Windows)

Нужны [uv](https://docs.astral.sh/uv/) и Node.js 22+.

```powershell
pwsh -File scripts\dev.ps1        # ядро + интерфейс с горячей перезагрузкой
pwsh -File scripts\build-win.ps1  # установщик: desktop\release\Jarvis-Setup-<версия>.exe
```

На Linux ядро для Windows-установщика собирается без Wine: `scripts/build-core-win.sh`, затем
`cd desktop && npm run dist` (для значка exe нужен Wine).

## Устройство

```
desktop/   Electron + React: главное окно, оверлей поверх окон, аватар, трей, хоткеи; запускает ядро
core/      Python 3.12 + FastAPI: голос, команды, ИИ, агент, MCP, плагины, виджеты, пульт (HTTP + WebSocket)
docs/      CONTRACTS.md — API и события ядра; UI.md — правила интерфейса
scripts/   сборка и запуск
```

Данные — `%LOCALAPPDATA%\Jarvis` (настройки, база, модели, журналы); ключи API зашифрованы DPAPI.

## Разработка

```bash
cd core && uv sync && uv run pytest -q          # тесты ядра (на Linux — с платформой-заглушкой)
cd desktop && npm install && npm run typecheck  # проверка типов интерфейса
```

Интерфейс без Electron: `uv run python -m jarvis --platform fake --token devtoken --port 8799` и
`npm run web`, затем `http://127.0.0.1:5173/?core=http://127.0.0.1:8799&token=devtoken`.
