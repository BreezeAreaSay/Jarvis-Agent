# Jarvis

Локальный **Agent Runtime** для ПК: демон, который понимает текстовые и голосовые команды на русском,
работает с ОС и приложениями, планирует и проверяет сложные задачи, использует инструменты и навыки,
помнит пользователя и его проекты. Голосовой ассистент, CLI и desktop UI — клиенты этого рантайма.

> **Статус:** этап проектирования. Кода пока нет — сначала архитектура, контракты и порядок работ.

## Главное

- **Local-first:** локальные модели (llama.cpp / LM Studio / Ollama через OpenAI-совместимый API),
  локальные STT/TTS, локальное хранилище; облако — только как опция.
- **Каскад вместо одной LLM:** детерминированные команды → рецепты → агентный цикл
  Planner / Executor / Verifier.
- **Безопасность с первого дня:** единая точка исполнения действий с политикой, подтверждениями,
  аудитом и журналом эффектов.
- **Навыки:** руководства из [AI-Dev-System](https://github.com/BreezeAreaSay/ai-dev-system) (MCP) +
  исполняемые рецепты, которые Jarvis учит на повторяющихся сценариях.
- **Windows-first:** UI Automation как основной путь управления интерфейсом, vision — запасной.
- **Поставка:** `.exe`-установщик, обновления из GitHub Releases только с разрешения пользователя.
