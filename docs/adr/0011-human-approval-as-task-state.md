# ADR 0011. Подтверждение человеком — состояние задачи

- **Статус:** Принято
- **Дата:** 2026-10-01

## Контекст

Подтверждение нельзя делать через `input()` в ядре: позже его будут давать UI и голос, а CLI может
закрыться, пока задача ждёт.

## Решение

- Объект `ApprovalRequest` и состояние WAITING_CONFIRMATION.
- Клиенты отвечают через `TaskService.resolve_approval`: `approve_once`, `deny`, `deny_and_abort`.
- Одобрение привязано к `tool_call_id` и `arguments_hash` и исполняется один раз; срок — 30 минут, затем
  считается отказом.
- Постоянных разрешений («разрешить всегда») в Stage 0 нет.
- Авто-клиент движка eval пользуется тем же API.

## Альтернативы

- `input()` в ядре.
- Колбэки и future в памяти — теряются при выходе.
- Постоянные разрешения сейчас — расширение объёма и риск.

## Последствия

- UI и голос переиспользуют механизм без изменений ядра.
- CLI поддерживает команды `approvals`, `approve`, `deny`, `resume`.
